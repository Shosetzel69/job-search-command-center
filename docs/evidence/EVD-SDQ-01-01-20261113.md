|---|---|
| `scripts/shared_corpus_repository.py` | `assess_record_quality`: deterministic `VALID/INCOMPLETE/INVALID`; field provenance only if explicitly supplied by trusted adaptor (`UNKNOWN` otherwise), stable issue codes, source/run identity, hashed posting key. `prepare_posting` rejects `INVALID`, stores `job_quality` in the existing payload, and suppresses future/invalid publication dates. `project_collection` reuses existing incomplete-source lifecycle suppression on rejection. |
