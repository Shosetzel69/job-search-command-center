# Mod de lucru

1. Cerintele si defectele sunt inregistrate ca GitHub Issues.
2. Fiecare schimbare foloseste un branch dedicat.
3. Schimbarea este integrata prin pull request.
4. Pull requestul mentioneaza issue-ul si criteriile verificate.
5. Branchul `main` contine doar versiuni coerente.
6. Secretele si datele personale nu se adauga in repository.
